# Improvado plugin for BB

Connect your BB agents to [Improvado MCP](https://github.com/tekliner/improvado-mcp) and ask questions about the marketing data in your Improvado workspace.

The plugin ships one skill, `improvado-mcp`, that shows agents how to connect the hosted server and what to ask. The server is hosted by Improvado; its implementation is not in this repository.

Install:

```bash
bb plugin install git:https://github.com/tekliner/improvado-mcp.git --subdirectory bb-plugin
```
